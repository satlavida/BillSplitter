Invisible in all prior Go tests because they build the router directly (`New(...).Router()`) without the `Logging` wrapper, and invisible in the first round of Playwright coverage because nothing yet opened a live SSE connection from the browser. Only surfaced once a real two-tab Playwright test subscribed to `/events` against the real `go run ./cmd/server` binary. Fixed by adding a `Flush()` method to `statusWriter` that forwards to the underlying writer's `Flusher`; regression-guarded by `middleware/logging_test.go`'s `TestLoggingPreservesFlusher`.
